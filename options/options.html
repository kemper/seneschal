Seneschal

Two things on wardenfall.com: a Cmd-K command palette, and a floating quick menu. Either can be switched off entirely. Quick menu entries go either to a path, or to a menu entry by name — which is how you reach sub-navigation that only exists once you are inside its parent door.

What runs on the page

Side of the screen

Entries

Path — /market, or a full https:// URL (external links open in a new tab).
Menu entry name — matched against what the link says on screen, ignoring case, emoji and the trailing dot: craftables matches 🛠 CRAFTABLES ●. Wrap it in slashes for a regular expression: /^hunt/i.
Open first — where to go when that entry is not on the current page. Seneschal navigates there, waits for the menu to render, and clicks it. If it never shows up you get a visible warning rather than a button that quietly does nothing.
